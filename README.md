### Backend (`.env`)

MONGODB_URI=your_mongodb_uri \

## Getting Started

### 1. Clone the repo
```
git clone https://github.com/jdylantapp/leads-management-api.git
cd leads-management-api
```
---

### 2. Install dependencies

#### Backend
```
cd backend
npm install
```
#### Frontend
```
cd frontend
npm install
```
---

### 3. Run locally

#### Backend
```
npm run dev
```
#### Frontend
```
npm run dev
```
